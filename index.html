Política de Privacidade — ROBOCOP 3 - Um novo amigo

Última atualização: Novembro de 2026 (Versão 6.1.4)

Resumo: A extensão ROBOCOP 3 - Um novo amigo (ROBÔ-COP) é uma ferramenta estritamente corporativa de produtividade e automação operacional destinada ao Centro de Operações (COP). Nós não comercializamos dados, não monitoramos a navegação pessoal na internet, não executamos códigos remotos externos e não compartilhamos nenhuma informação com terceiros, parceiros comerciais ou redes de publicidade.

1. Escopo de Atuação e Domínios Autorizados

A extensão atua exclusivamente dentro dos sistemas corporativos internos autorizados em seu manifesto (manifest.json), não tendo acesso a nenhum outro site visitado pelo usuário:

  • Sistema Integrado de Recuperação (SIR — Embratel/Claro): e endereços internos de intranet (e 10.13.98.10);
  • Oracle Field Service (TOA / OFSC):;
  • Servidor Interno da Operação COP:.

2. Informações que Coletamos e Finalidade

Para fornecer suas funcionalidades de automação, filtros operacionais e integração de chamados, a extensão processa estritamente as seguintes informações:

  • Informações de Identificação Corporativa: junto ao painel interno da supervisão.
  • Informações de Autenticação e Sessão (cookies): A extensão acessa cookies de sessão de curta duração exclusivamente nos domínios internos do SIR. Essas informações são utilizadas unicamente para autenticar as ações solicitadas pelo próprio operador (como consulta de histórico, geração de itens, vínculo de notas e encerramento sincronizado entre o TOA e o SIR), evitando múltiplos logins manuais.
  • Dados de Chamados Operacionais: Leitura de identificadores técnicos do chamado ativo na tela (número de recuperação/bilhete REC, RAL ou TCQ, ano, item, Centro Funcional, código da atividade no Oracle TOA e observações técnicas), utilizados exclusivamente quando o operador aciona os botões auxiliares de automação, carimbos ou abertura de janela dedicada.
  • Área de Transferência (clipboardRead e offscreen — Uso Estritamente Local): Quando o operador clica manualmente no botão "Colar Resolução" no SIR ou "Puxar Clipboard Agora" no Popup, a extensão lê o texto copiado na área de transferência via documento Offscreen temporário (Manifest V3) unicamente para higienizar emojis e caracteres incompatíveis com a codificação legada ISO-8859-1 (ColdFusion) antes de preencher o campo de observação. O conteúdo da área de transferência nunca é enviado para servidores externos.
  • Preferências Locais, Alarmes e Notificações (storage, alarms, notifications, tabs e scripting): Temas visuais escolhidos, ativação/desativação de botões padrão, controle da janela dedicada do chamado no SIR, comunicados da supervisão e lembretes opcionais de ergonomia/bem-estar (hidratação, postura e regra visual 20-20-20) são gerenciados localmente no navegador via chrome.storage.local e chrome.storage.session.

3. Como os Dados São Utilizados

Todas as informações tratadas possuem como finalidade única e exclusiva:

  • Viabilizar a funcionalidade técnica principal da extensão (produtividade e integração operacional entre Oracle TOA e SIR);
  • Garantir que as ações e carimbos executados no sistema reflitam com precisão a identidade do operador autenticado;
  • Exibir comunicados operacionais da supervisão e evitar a abertura de janelas duplicadas e retrabalho durante o plantão.

4. Declaração de Uso Limitado (Chrome Web Store Limited Use Disclosure)

O uso das informações recebidas das APIs do Google Chrome pela extensão ROBOCOP 3 - Um novo amigo cumpre integralmente a Política de Dados do Usuário da Chrome Web Store (Chrome Web Store User Data Policy), incluindo os requisitos de Uso Limitado (Limited Use), bem como a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018):

  • Não vendemos nenhuma informação ou dado pessoal ou corporativo a terceiros;
  • Não transferimos dados para terceiros, corretores de dados (data brokers), plataformas de análise externas ou redes de publicidade;
  • Não utilizamos dados para publicidade personalizada, retargeting, determinação de capacidade de crédito, concessão de empréstimos ou qualquer finalidade alheia ao propósito único operacional da extensão.

5. Armazenamento, Segurança e Controle pelo Usuário

Os dados de sessão do operador são mantidos temporariamente em ambiente local ou na API interna corporativa da operação (Intranet/VPN), expirando automaticamente com o encerramento da sessão de trabalho. Não há coleta ou armazenamento de senhas.

A extensão é 100% aderente ao Manifest V3: todo o código executável reside dentro do pacote oficial publicado na Chrome Web Store, sem uso de código hospedado remotamente.

O operador pode revisar ou alterar seus dados de perfil, temas e botões a qualquer momento diretamente no menu de configurações da extensão, ou remover integralmente todos os dados locais desinstalando a extensão do navegador.
